# Démo — Réassort du jour avec coefficient de facteurs externes

Ouvrir `index.html` dans un navigateur (aucune installation, aucun serveur).

- La commande est pré-calculée par le réapprovisionnement automatique (colonne **Proposition auto**).
- La colonne **Coef. facteurs externes** ajuste la proposition selon la météo, les vacances, les événements, les promos…
  Survoler le coefficient affiche le détail par facteur.
- **Qté conseillée** = proposition auto × coefficient, arrondie au colis (PCB).
- Le gestionnaire peut modifier chaque quantité (saisie ou ± 1 colis), puis **Valider la commande** en un clic.
- Le panneau de gauche permet de simuler les facteurs en direct pendant la démo.

Les données (articles, sensibilités, prix) sont fictives et se modifient dans le tableau `PRODUCTS` du script.
